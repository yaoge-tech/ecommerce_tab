# Migoo · Commerce Tab — 交互 Demo

美国市场电商 tab 的框架 demo。单文件 `index.html` + 本地 `assets/`,零依赖。

**在线预览**:https://yaoge-tech.github.io/ecommerce_tab/

本地打开:

```bash
python3 -m http.server 8100
```

然后访问 `http://localhost:8100`。

## 这个 demo 演示什么

**双列流货架为体,AI 能力做成流内插件** —— 不另起一条 AI 流,AI 生成物与商品卡同构地混排在同一条双列流里。

### 首页

- 顶部:serif 问候 + Ask 输入框 + query 推荐 chips
- **Worth a look**:只显示收藏夹里有更新的商品,每卡带事件行;无更新时整区隐藏
- **Daily Edit**:双列流,商品卡 + 三类插卡混排

### 三类流内插卡

| 卡型 | 触发 | 点击后 |
|---|---|---|
| **问句卡** | 类目级困惑 | 会话作答 |
| **对比卡** `STILL DECIDING?` | 看过两个同类且都没下单 | 会话发起对比 |
| **接续卡** `STILL LOOKING?` | 上次会话未收口的决策 | 带历史回到那个会话 |
| **橱窗卡** `FROM YOUR CHATS` | 从聊天长出的合集 | 会话内双列陈列 |

插卡不在卡上给结论——它唤起「未完成状态」,把人送进会话,由会话完成回答。

### 交互要点

- **点商品卡上的 ✦** = 唤起 composer 并预先引用这件商品(附件范式),与顶部输入框共用一套 UI。chips 分两类:query 型键入不发送,能力型(Try it on)直接执行
- **所有进会话的路径**统一时序:query 先出 → 思考 2s → 逐段流式打出 → 商品列表/对比表整块淡入
- **PDP**:半屏 ↔ 全屏 sheet,支持拖拽与滚动展开手势
- **Likes 委托台**:收藏即托管监控,价格/库存变动回到首页 Worth a look

## Demo 开关

页面顶部两个按钮切换收藏夹状态,同时驱动首页和 Likes 页:

- `收藏有更新` — 有事件的完整形态
- `收藏夹无商品更新` — 安静态

## 改数据

`<script>` 里:

- `P` — 商品(名称/价格/图/推荐理由)
- `PDPD` — PDP 详情数据
- `home()` 里的 `cells` — 双列流排布

商品图放在 `assets/`,新增须亲眼确认图片内容再引入。
